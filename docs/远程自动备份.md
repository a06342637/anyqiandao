# 远程自动备份

在 **设置 → 远程自动备份** 中填写配置并保存。默认关闭总开关和两个目标，不会自动连接示例地址。

1. 设置间隔、天/小时、执行时刻和时区，默认北京时间每天 04:30。
2. 选择应用数据包或完整备份，勾选 OSS、SFTP 或两者。
3. 填写目标，保存设置，点击“测试连接”验证创建、列举和删除权限。
4. 点击“立即备份”验证结果；开启总开关并保存后，计划持续运行。

停机期间错过的计划在重启后补做一次，不追补每一次。修改时间、间隔或时区会重新计算下次时间。手动备份不改变定时计划。备份与签到队列独立，通过 SQLite 快照读取一致的数据；更新维护期间不启动新的备份。单实例同一时刻只执行一次远程操作。

## 阿里云 OSS

- 地域示例：`cn-hangzhou`。使用阿里云官方 OSS SDK 的 V4 签名。
- 填写 Bucket、AccessKey ID、AccessKey Secret 和目录前缀，根目录可留空。
- 使用私有 Bucket。凭证需要对应目录的 PutObject、ListObjects、DeleteObject 权限。
- 同地域 ECS 可使用内网 Endpoint；本地电脑或其他云服务器通常使用公网。
- 自定义 Endpoint 留空时按地域和内网选项生成，填写时以自定义值优先，仅支持 HTTPS。

## SSH / SFTP

- 填写服务器地址、SSH 端口、用户名，选择密码或 SSH 私钥；加密私钥可填写口令。
- 保存目录必须是服务器绝对路径，不存在时自动创建；用户需要该目录的读写和删除权限。
- 首次身份验证成功后自动记录主机公钥指纹，失败的登录不会记录。后续指纹不符会拒绝连接；核实服务器重装或密钥更换后，使用“重置信任”。修改主机或端口会清除旧指纹。
- 上传先写入 `.part`，完成后改名为 ZIP，失败文件不会计入成功备份保留份数。
- 目录浏览只显示子目录；也可直接填写尚未创建的新目录。

密码、AccessKey Secret、私钥和口令使用现有 AES-256-GCM 密钥加密保存。API 仅返回是否已保存，留空保存保留原值。备份配置不会随应用数据导出，完整快照也会移除远程存储配置。

## 保留份数与日志

每次生成 ZIP 并上传至所有已启用目标。每个目标上传成功后才清理该目标超过保留份数的备份，按生成时间保留最新文件。文件名包含本实例的随机标识，仅完整匹配本实例命名的文件参与清理，其他文件、其他实例和未完成上传不会删除。

一个目标失败不阻止另一个目标上传。上传成功但清理失败显示提醒，已上传的包保留。关闭总开关只停止定时执行，不删除配置或远程文件。

运行日志的 **备份** 分类包含手动导出、恢复、配置变更、连接测试、定时/手动上传及旧备份清理结果。全部使用现有日志表，按 **日志保留与自动清理 → 运行 / 账号日志保留天数** 清理，也支持筛选后手动清理。设置面板只保留最后一次状态，不是另一个历史日志库。

## 恢复

**应用数据包（推荐）**：下载 ZIP 后，在“设置 → 备份与恢复”直接选择 ZIP，或解压后导入 `backup.json`。先暂停队列并等待当前任务结束；按账号合并恢复，不删除已有数据。包内包括账号密码、凭证、代理、计划、签到统计和运行设置，不包括运行日志、临时会话或远程存储凭证。JSON 解压大小上限 64MB。

**完整备份**：额外包含程序源码、SQLite 一致性快照、原加密密钥、管理员密码哈希及基础 `.env`。快照中运行日志、会话、任务和远程备份配置已移除，队列设为暂停。停止应用后解压到独立目录，核对 `.env` 中域名、端口等部署参数，按 `RESTORE.txt` 运行 `scripts/deploy.sh`。核对账号和计划后再继续队列，并重新配置远程备份。宿主机自定义反代、证书和其他外部文件需要单独保留。

ZIP 中包含账号密码等敏感数据，完整 ZIP 还包含原密钥；请保存到自己的私有存储，并限制访问权限。

## 版本更新

默认使用 [a06342637/anyqiandao](https://github.com/a06342637/anyqiandao) 的稳定 Releases。设置中也可填写 `用户名/仓库` 或 GitHub HTTPS 地址，留空保存恢复默认。已有自定义源会保留。

发布需包含 `any-signin-assistant-v版本.tar.gz` 与 `release.json`。维护者运行 `python scripts/build_release.py` 生成包；推送 `v版本` 标签也会通过 GitHub Actions 校验并发布。Linux 部署脚本安装更新执行器后，可在设置中检查和安装更新。
