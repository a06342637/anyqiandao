any签到助手 v0.5.2 · 安全部署说明

完整的新机器部署教程请阅读 README.md 的“新机器部署教程”。

1. 在新服务器 SSH 终端执行 sudo -i，安装 git 和 ca-certificates。
2. git clone https://github.com/a06342637/anyqiandao.git /opt/any-signin-assistant
3. cd /opt/any-signin-assistant
4. 有域名时：bash scripts/deploy.sh https://你的域名（先解析域名、放行 80/443）。
   无域名时：bash scripts/deploy.sh（默认仅监听 127.0.0.1）。
5. 无域名时，在自己电脑建立 SSH 隧道：
   ssh -N -L 18780:127.0.0.1:18780 ubuntu@你的服务器IP
   端口按实际配置修改，在浏览器访问 http://127.0.0.1:18780。

公网 HTTP 不接受登录、账号或密钥传输。现有 HTTPS 部署升级时保留原配置。
管理员初始信息在服务器部署目录的 部署信息.txt，请勿公开。
更新优先使用设置中的一键更新，默认仓库 a06342637/anyqiandao。
手动备份下载 JSON，远程备份生成 ZIP；备份和恢复无需额外密码。
详情见 docs/安全与隐私.md 和 docs/远程自动备份.md。

Cloudflare Tunnel 回源可继续使用 http://127.0.0.1:应用端口；自动代理识别及旧版修复方法见 docs/Cloudflare-Tunnel.md。
