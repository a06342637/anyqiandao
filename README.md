# any签到助手 v0.4.0

私有部署的 AnyRouter 凭证提取、账号检测与自动签到工作空间。React / TypeScript / Vite 前端，FastAPI / Playwright / SQLite 后端。

## 功能

- 账号添加、CSV 分块导入、加密保存密码与凭证、编辑备注和账号密码、拖拽排序及分页。
- 批量仅重提已失效账号，或检测时自动修复失效 Cookie；网络错误和验证码不会触发重登。普通队列与签到队列分别可调 1–5 并发，同账号始终串行。
- 独立执行队列支持暂停、刷新、筛选、分页、跨页多选停止并删除，以及清理已结束任务；提高并发立即补充执行名额，降低并发保留正在执行的任务。
- 已添加账号不可重复添加，批量导入自动跳过且不覆盖密码。运行日志标明直连或每次实际选择的代理。
- 账号列表从序号、账号开始排列，桌面表格与平板/手机卡片适配；前后余额、期间消耗和网站回执在账号明细日志查看，复制与账号操作分组排列。
- 单个/批量导入 session 与 api_user，支持分隔文本及 GitHub 配置 JSON；自动标记为 Session 账号，无需密码，失效后保留并等待手动更新，不自动登录。
- 每个账号独立加载网站数据看板和 API 令牌；查看用量、趋势、模型分布、令牌额度/有效期/限制，复制网站已有令牌，不创建或修改令牌。
- 运行/账号日志、队列历史和签到明细分别设置保留天数与统一清理间隔；日志与签到明细支持多选或按截止时间清理，等待/运行任务及相关记录受保护。
- 打开页面或重新登录默认进入仪表盘；账号列表的「余额」只显示当前金额与北京时间「上次签到」，具体操作结果保留在明细日志。
- 按北京时间每日 00:00 划分签到日，以「余额变化＋期间消耗」核对固定 $25 到账；消费不取消当日签到依据，其他金额增加不直接视为签到。
- 今天 / 近 7 天 / 近 30 天统计同样按北京时间划日，不随界面显示时区改变；领取前在同一浏览器会话中复核最新余额，已观察到今日到账就不再发送领取请求。
- 余额或消耗暂时读不全时保留上一份完整观察，不把不同请求的值混算，也不清空已知余额；账号列表和仪表盘明确区分加载中、读取失败与真实空列表。
- 恢复备份按最新余额观察时间防止倒退，同时合并同一账号同一天的确认依据；较新但未确认的快照不会抹掉已签到依据，旧回执可以补齐确认但不覆盖较新余额。
- 按今天、近 7 天、近 30 天统计签到新增；新版确认成功每次固定计 $25，邀请划转不混入奖励，已签过和待确认不重复累计，旧记录保留原统计口径。
- 队列、账号、签到计划、统计明细与分类日志分页，每页 5 / 10 / 15 / 20 / 30 / 50 条。
- 底部居中显示真实任务结果；刷新等待接口返回，不以固定延时冒充成功。
- HTTP / SOCKS5 / SSH 代理，指纹确认、代理连通性检测和明确的直连模式。
- 设置一键备份与合并恢复账号、密码、凭证、代理、计划、备注及签到统计。
- 在线版本检测、源码校验、完整备份、健康检查与失败回滚。默认更新源为 [a06342637/anyqiandao](https://github.com/a06342637/anyqiandao) 的 GitHub Releases，支持自定义仓库。
- 远程自动备份支持阿里云 OSS（V4 签名）与 SSH / SFTP（密码或私钥），按天/小时定时执行、停机补做一次、手动备份、连接测试、目录浏览及独立保留份数。备份日志统一筛选与自动清理。
- 应用数据 ZIP 可直接导入恢复；完整 ZIP 额外包含程序源码、数据库快照和原密钥。远程存储凭证加密保存，备份包不包含远程存储凭证或运行日志。
- 设置中自定义网站名称与图标文字，左上角、登录页、浏览器标签同步更新，外观设置随备份恢复。
- 统计从同一数据库快照生成；中断或超时单列为待确认，未来时间记录不提前累计，小额余额保留原始精度后汇总。

## 首次部署

将项目源码（包括隐藏文件）上传到 Ubuntu 22.04+ / Debian 12+ 服务器，在项目目录运行；缺少的 Docker Engine、Compose 和 Python 3 由脚本自动安装：

```bash
sudo bash scripts/deploy.sh
```

依次询问端口、用户名和密码：端口回车随机空闲值，用户名回车为 `admin`，密码回车生成随机强密码。自动写入配置后，以 `http://IP:端口` 启动；不默认安装证书或占用 80/443，自行配置 HTTPS 反代与防火墙。

重复部署保留已有配置和数据，先构建、备份，再切换；与在线更新互斥。旧的 Caddy HTTPS 部署仍按原方式运行。不会自动卸载已有 Docker、接管其他目录的部署或清理其他服务。

完整的上传、回车默认值、密码查看、更新与排错步骤见根目录 `部署教程.txt`。项目只需携带源码，不需要本机虚拟环境、依赖缓存或旧发布包；浏览器运行环境在服务器的 Docker 镜像中下载。

完整步骤、可选 HTTPS 反代说明、发布新版本的方法，见 [部署与更新说明](docs/v0.3.0-部署与更新.md)。操作说明见 `使用说明.txt`，回滚说明见 `docs/升级与回滚.md`。

## 安全和数据

- AES-256-GCM 字段加密、Argon2 管理密码哈希、HttpOnly/SameSite Cookie、CSRF 与来源校验。
- 数据库与密钥不匹配时拒绝启动，不生成替换密钥。账号密码加密保存，用于 Cookie 失效后的自动重新登录。
- 浏览器会话临时隔离；签到发送后结果不明时，不自动重发。
- 网站数据查询只使用当前凭证，不登录或签到；结果加密暂存 10 分钟，令牌不会写入日志、浏览器本地存储或 JSON 备份。
- 阻止网站页面自发的签到请求，检测、令牌查询和凭证修复不会顺带领取，也不改写最近签到任务时间。独立保存每日余额观察与明确回执，今日已有依据时只刷新余额、不重复提交签到。
- 首次读取或跨日没有当日基线时不凭空补算；消耗数据缺失、计数重置和跨日回执保守处理。邀请划转恰好为 $25 时仅凭余额无法完全区分，详情保留在日志中。
- 容器非 root、只读根目录、资源限制与日志轮换。Docker 更新权限不交给 Web 容器。
- JSON 备份含明文凭证，下载前会提示，只应保存在私密位置。完整服务器备份还需保留原密钥。
- 不上传任意脚本、不执行用户输入的 shell 命令、不修改 GitHub Secrets。在线更新只使用管理员明确选择的可信项目发布源。

内置签到函数来自固定提交 `9f1394d0f5ccf687eb21a0307ef4ccd4e71ecd3a` 的 [millylee/anyrouter-check-in](https://github.com/millylee/anyrouter-check-in)，BSD-2-Clause，来源和许可证见 `app/vendor/`。它不是本助手的程序更新仓库。

数据库版本：8，新增账号独立加密每日签到依据与固定奖励字段，保留短期加密网站查询缓存；原账号、凭证和历史记录无损保留。旧记录缺少的消耗不补造。删除队列任务保留日志及统计；清理签到明细会减少历史统计，但不清除每日签到依据和账号最近任务时间。备份恢复支持每日依据，并按 api_user 隔离身份。签到时间和间隔仅在签到管理设置。
